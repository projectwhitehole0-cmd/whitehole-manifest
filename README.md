# Whitehole Manifest Registry

This repository hosts the public Model Context Protocol (MCP) manifest (`server.json`) for **Whitehole**, enabling automated AI agent discovery and decentralized tool routing.

---

## Manifest Overview

* **Server Name:** Whitehole
* **Protocol Standard:** Model Context Protocol (MCP) v1.0 / JSON-RPC 2.0
* **Transport Type:** HTTP / Streamable-HTTP
* **Production Endpoint:** `https://mindful-gentlenesss.up.railway.app/mcp`

## Directory Indexing & Usage
